一条管道，八个关口

scikit-learn 把"预处理 + 模型"叫作 Pipeline，也就是管道。数据从左边流进来，变成右边的决策。橙红色的水滴是漏点：数据泄漏最容易发生的地方。点任意一个关口看看。

三个项目，三类任务

建议按顺序学：回归项目把"时间"讲透，分类项目把"业务决策"讲透，聚类项目讲没有标签时怎么判断好坏。每页的进度保存在你的浏览器里。

泄漏博物馆

数据泄漏是这门课的头号反派：模型在训练时偷看到了上线时拿不到的信息，线下分数漂亮，上线就露馅。三个项目里一共布置了 14 个漏点，每个都有"泄漏版 vs 正确版"的真实对比。全部排查完，你会拿到一枚徽章。

热身：这是哪类任务？

机器学习项目的第一步，是把业务问题翻译成正确的任务类型。

预测下个月每家门店的销售额

要预测的是一个连续的数。注意它和房价一样有时间顺序，要按时间切分。

判断一笔信用卡交易是不是盗刷

二分类，而且盗刷极少，类别严重不平衡，准确率陷阱比流失项目更严重。

没有任何标签，把 10 万篇用户评论按话题分组

没有标签、要找出"自然的分组"，就是聚类。

根据历史数据，判断新来的简历应该进入"技术岗 / 销售岗 / 职能岗"哪个池子

有历史标签的多分类。另外要警惕：历史数据里的偏见会被模型学走。

这门课怎么教

传统的骨架

  • 三个项目走完全相同的 8 步流程，流程本身就是知识。
  • 每一步固定结构：业务方的话 → 为什么 → 代码 → 结果 → 常见坑 → 小测验 → 官方文档。
  • 代码就是真正跑出结果的代码，可以复制到自己的 Python 里运行。
  • 每个项目末尾有复盘清单和课后作业（附原始脏数据下载）。

新的玩法

  • 剧情：你是新入职的数据科学家，三位业务方会给你提需求、挑毛病。
  • 先猜后看：关键数字先锁住，你先下注再揭晓。猜错的地方记得最牢。
  • 找茬：在原始数据里亲手点出脏数据，还有陷阱题。
  • 泄漏版 vs 正确版：每个漏点都能一键切换，真实对比分数。
  • 实验台：拖动阈值、深度、K 值，背后都是真实的 sklearn 结果。
  • 向老板汇报：从一堆说法里挑出能对老板讲的结论。

项目文件与运行方式

整个网站由一条命令生成。改了数据规律或模型代码，重新运行即可，网页上的数字和代码会自动同步。如果某个教学结论（比如"泄漏版分数虚高"）不再成立，构建会直接报错。

项目结构
完整机器学习项目介绍/
├── build.py               一键重建：生成数据 → 跑三个项目 → 导出网页数据
├── ml/
│   ├── make_data.py       生成三份带"坑"的仿真业务数据（固定随机种子）
│   ├── regression.py      项目 A 完整流程（用 # %% step:xxx 分段，分段即网页上的代码块）
│   ├── classification.py  项目 B 完整流程
│   ├── clustering.py      项目 C 完整流程
│   └── common.py          导出工具
├── site/                  网站本体，双击 index.html 即可离线打开
│   ├── assets/            样式与交互组件（无第三方依赖）
│   └── data/              原始脏数据 CSV + 预计算结果 *.js
└── models/                训练好的整条 Pipeline（joblib）

pip install scikit-learn pandas numpy joblib
python build.py
